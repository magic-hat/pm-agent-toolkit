# Learning

What the user learns: articles, courses, talks, notes about books, and ideas to keep.

## File names

`<topic>.md` or `YYYY-MM-DD <source title>.md`.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `status`: active or done.
- `source`: the link or the title.

## Rules for this folder

- Write what the user will do differently because of the source. Do not write only a summary.
