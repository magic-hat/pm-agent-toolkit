# Career

The goals and priorities of the user, the feedback that the user gets, and the weekly career checks.

## File names

`goals.md` for the current goals. `YYYY-Www career check.md` for each weekly check, for example `2026-W45 career check.md`.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `status`: active or done.

## Rules for this folder

- Keep `goals.md` short: 2 or 3 goals, and how the user will know that each goal is met. Start from `_templates/goals.md`.
- Use `_skills/weekly-career-check` one time each week.
- If the vault is on a work laptop, write only about growth in the current role. Information that the user does not want the employer to read must not go in this folder.
