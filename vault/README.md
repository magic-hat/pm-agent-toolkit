# Vault

My working memory as a PM. `AGENTS.md` is written for agents, but it's also the quickest way for a person to learn the layout.

- `open-actions.md` has everything I owe and everything I'm waiting on.
- `linked-resources.md` lists notes that also live as a shared doc somewhere else.
- `changelog.md` has a running entry for each day: what each session did and why.
- Every numbered folder has its own `README.md` with the rules for that folder.
