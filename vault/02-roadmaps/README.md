# Roadmaps

Roadmap snapshots and the reasons for each change.

## File names

`YYYY-QN <product> roadmap.md` or `YYYY-MM-DD <product> roadmap.md`.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `status`: draft, shared or superseded.
- `product`: required.

## Rules for this folder

- If the roadmap changes and other people will see the change, save a new snapshot. Do not edit an old snapshot.
- In each new snapshot, write what moved and why, under the heading `## Changes since last version`.
- Link each roadmap item to its PRD note or project note, if one exists.
