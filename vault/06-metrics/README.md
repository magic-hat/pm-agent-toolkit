# Metrics and data

Metric definitions, snapshots, analyses and the questions that they answered.

## File names

`<metric name>.md` for a definition. `YYYY-MM-DD <analysis title>.md` for an analysis.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `status`: active, done or superseded.
- `source`: the dashboard, query or export that is the source of the numbers.

## Rules for this folder

- Write the definition of each metric. Include what the metric does not count.
- For each number, write its source and the date when the number was true.
- If the policy of the user's company does not permit raw data exports in local files, do not put them here. Add a link to them instead.
