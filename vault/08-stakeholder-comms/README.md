# Stakeholder comms

Updates, announcements and escalations that the user sends: weekly updates, launch notes and executive summaries.

## File names

`YYYY-MM-DD <audience> - <topic>.md`.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `status`: draft or sent.
- `related`: the notes that the update is about.

## Rules for this folder

- Write the version that the user will send. If the audience changes, save a new file.
- After the user sends the update, set `status: sent`. In `source`, write where the update went.
