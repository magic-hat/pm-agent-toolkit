# Meeting notes

One note for each meeting. Make the note from a transcript, or from a brain dump after the meeting.

## File names

`YYYY-MM-DD <meeting name>.md`.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `status`: done.
- `related`: link the people note of each attendee, and each project or PRD that the meeting discussed.
- `date`: the date of the meeting.
- `source`: transcript, brain dump, or notes (written notes from the user or a different person).

## Rules for this folder

- Start from `_templates/meeting-note.md`. Use `_skills/meeting-from-transcript` or `_skills/meeting-brain-dump`.
- Put the decisions and the actions first. A summary with no actions is the least useful part.
- Copy each action into `open-actions.md`. Give the owner, the due date if the meeting gave one, and a link to this note.
- If you learn new information about a person, add it to the note for that person in `11-people/`.
