# Strategy

Long-term thinking: product vision, bets, positioning, product goals for a quarter or a year, and decision memos that affect more than one project. Career goals go in `12-career/`.

## File names

`<topic>.md`, for example `usage-pricing-strategy.md`. For product goals, give the period: `YYYY-Qn product goals.md`, for example `2027-Q1 product goals.md`. If you do not know the year, ask the user. For a memo, add the date: `YYYY-MM-DD <memo title>.md`.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `status`: draft, active or superseded.
- `date`: the date of the last revision.

## Rules for this folder

- Put the decision or the point of view first. Put the evidence after it.
- If a strategy changes, do not overwrite the old note. Create a new note.
- Set the old note to `status: superseded`, and add a link to the new note in its `related` field.
- Link the customer feedback, metrics and competitive notes that the argument uses.
