# Competitive

Notes about competitors and alternatives. Include "do nothing" and "build it ourselves" as alternatives.

## File names

`<competitor>.md`. For a specific launch, add a dated note: `YYYY-MM-DD <competitor> - <launch>.md`.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `status`: active or archived.
- `source`: a public link, an analyst report, a customer conversation, or a rough note from the user. Information from a rough note is not verified until a different source confirms it.

## Rules for this folder

- Keep verified facts separate from information that nobody verified.
- Write what each alternative does well. A note that lists only weaknesses does not help a decision.
