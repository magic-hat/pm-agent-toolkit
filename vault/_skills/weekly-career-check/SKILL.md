# weekly-career-check

1. Read `12-career/goals.md`. If the file does not exist, ask the user for 2 or 3 goals and how the user will know that each goal is met. Then create the file from `_templates/goals.md`.
2. Read the daily notes and the meeting notes from the last 7 days. Read the actions in `open-actions.md` that closed in the last 7 days.
3. Ask the user these 4 questions, one at a time:
   1. What moved one of your goals forward this week?
   2. What used time but did not move a goal?
   3. Are your priorities for next week the correct ones?
   4. Is there one question to ask your manager or a mentor?
4. Tell the user about each pattern in the vault that the user did not mention. For example, a goal with no activity for 3 weeks.
5. Write `12-career/YYYY-Www career check.md`.
6. Add a bullet to today's entry in `changelog.md`. Then commit.
