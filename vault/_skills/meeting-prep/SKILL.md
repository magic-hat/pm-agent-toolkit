# meeting-prep

1. Find who attends the meeting and what it is about. If a calendar is connected, read the calendar. If not, ask the user.
2. Read the note for each attendee in `11-people/`. Include the most recent log entries.
3. In `open-actions.md`, find each open action that is related to an attendee or to the topic.
4. Find the 2 most recent meeting notes with the same people or the same topic.
5. Find each project note or PRD note that changed in the last 14 days and is related to the meeting.
6. Give the user a brief of 20 lines or fewer. Include the open actions, the changes since the last meeting, and 2 or 3 topics to raise.
7. Save the brief only if the user asks. If you save it, add a bullet to today's entry in `changelog.md` and commit.
