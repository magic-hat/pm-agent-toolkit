# People

One note for each person that the user works with.

## File names

`<First Last>.md`.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `title`: the name of the person.
- `status`: active or moved on.
- `related`: the team and the projects of the person.

## Rules for this folder

- Start from `_templates/person.md`.
- Record the role, the team, what the person owns and what the person drives now.
- Keep a dated log of conversations. List the open actions with the person.
- Write only text that the user is comfortable for that person to read.
