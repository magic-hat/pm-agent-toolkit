# Products

One overview for each product or area that the user owns. The overview gives what the product is, who uses it, the main metrics, the owners, and links to related notes.

## File names

`<product>.md`. The name must match a value in the product list in `AGENTS.md`.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `status`: active or archived.
- `product`: the product that the overview is about.

## Rules for this folder

- The overview is the first note to read about a product. Keep it short, and link to other notes for detail.
- If the ownership, the positioning or a main metric changes, update the overview.
