# Projects

Cross-functional work with a goal and an end date: launches, migrations and pricing changes.

## File names

`<project name>.md`. If a project becomes large, put its supporting notes in a subfolder with the same name.

## Front matter

Use the 7 fields in `AGENTS.md`. These rules apply in this folder:

- `status`: planned, active, done or archived.
- `owner`: the person who is accountable.

## Rules for this folder

- Start from `_templates/project.md`.
- Keep a dated log at the end of the note, so that a person or an agent can learn the current state quickly.
- When a project ends, write a short retrospective and set `status: done`.
